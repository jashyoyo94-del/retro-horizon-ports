RETRO HORIZON PORTS CATALOGUE

Files:
- index.html: website
- ports.json: catalogue data

To use:
1. Upload both files into the same folder in your GitHub repository.
2. Deploy that repository with GitHub Pages or connect it to Netlify.
3. To add a port, edit ports.json and add another object inside the JSON array.
4. Keep index.html and ports.json in the same published folder.

Important:
- Empty downloadUrl and guideUrl fields intentionally show "Details coming soon".
- Check compatibility and permissions before publishing any downloads.
- This starter catalogue contains example project entries based on information previously discussed. Review every listing before making the site public.
